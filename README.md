Para documentação de arquitetura, padrões visuais e instruções para alterações futuras, consulte o arquivo:
👉 **[PROJECT_GUIDE.md](./PROJECT_GUIDE.md)**

---

## 🚀 Como Iniciar

1. Instalar as dependências:
   ```bash
   npm install
   ```

2. Iniciar o servidor de desenvolvimento:
   ```bash
   npm run dev
   ```

3. Compilar para produção:
   ```bash
   npm run build
   ```
